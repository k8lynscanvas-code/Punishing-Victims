Extract this ZIP into one folder, then open index.html. Keep book-data.js, viewer.js, viewer.css and the pages folder together. Drag a page corner or use the arrows, page number, thumbnails or keyboard to navigate. On small screens the book shows one page at a time. Zoom opens the current page; fullscreen is available where supported. You can also upload the complete folder to your own static web hosting. This package contains page images, not searchable PDF text. The viewer includes StPageFlip 2.0.7 under the MIT license; see LICENSE.txt.
